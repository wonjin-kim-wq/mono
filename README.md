# mono

블랙·화이트 중심의 음악 웹앱 로컬 데모입니다.

## 실행

```sh
npm run dev
```

브라우저에서 http://localhost:3000 을 열어주세요. 별도 패키지 설치가 필요하지 않습니다.

## 동작

- 곡 제목, 아티스트, 장르, 분위기 검색
- 장르 필터, 좋아요 및 좋아요 라이브러리
- 음악 재생, 탐색, 음량, 셔플, 반복, 재생목록
- MP3/WAV/M4A/OGG 업로드 및 IndexedDB 파일 보관 (50MB 제한)
- 문의 작성, 상세 보기 및 localStorage 보관
- 데스크톱·태블릿·모바일 반응형 레이아웃

샘플 곡 정보는 디자인 데모이며, 오디오는 SoundHelix의 샘플입니다. 사진은 Unsplash, 폰트는 Google Fonts에서 불러옵니다. 외부 리소스에는 인터넷 연결이 필요합니다. 업로드 음원은 실제 파일로 재생됩니다. 업로드·좋아요·문의는 해당 브라우저에만 저장되며 운영자 전송이나 서버 동기화는 지원하지 않습니다.
